# LinkedIn Sequence

Create two concise LinkedIn messages: an accepted-connection opener and one follow-up.

Rules:
- Message one earns a conversation; it does not pitch a meeting immediately.
- Message two adds a new insight or question and is sent only if there is no reply.
- Keep each message channel-native, conversational, and under 300 characters where possible.
- Use one verified observation and never invent a post, mutual connection, or trigger.

Return: `message1`, `message2`, `delayDays`, and `angle`.
